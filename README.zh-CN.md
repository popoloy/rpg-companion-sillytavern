# RPG Companion —— SillyTavern 扩展

一款适用于浏览器的沉浸式 RPG 扩展，可在美观且可自定义的 UI 面板中追踪角色数值、场景信息与角色想法，全部自动生成！兼容任意预设。可在「集成」与「单独」两种生成模式间切换，以控制上下文与生成方式。

> **本仓库的简体中文界面由社区汉化维护。** 扩展默认语言已设为简体中文，可在设置面板中随时切回 English。
> 原文文档见 [README.md](./README.md)。

## ✨ 功能特性

### 核心功能

- **📊 用户数值追踪器**：完全可自定义的数值，带可视化进度条、自定义状态字段、技能分区与动态物品栏管理
- **🌍 信息框仪表盘**：可配置的小组件，显示日期、天气、温度、时间、地点与近期事件
- **💭 在场角色面板**：追踪多名角色，支持自定义字段、关系徽章、角色专属数值与内心想法
- **🎭 浮动想法气泡**：可选功能，在聊天中将想法气泡显示在角色头像旁
- **🎲 经典 RPG 属性**：STR、DEX、CON、INT、WIS、CHA 六项属性，并支持掷骰
- **📦 高级物品栏系统**：多位置存储（随身、各存储点、资产），采用 v2 格式
- **🎯 角色数值**：为每名在场角色追踪生命值、精力或任意自定义数值，并带颜色渐变
- **📜 沉浸式 HTML**：在角色扮演中嵌入富有创意的 HTML/CSS/JS 元素，增强沉浸感
- **➡️ 剧情推进**：点击按钮即可推进剧情，可选择随机事件或自然延续
- **🎨 多种主题**：赛博朋克、奇幻、极简、暗色、亮色以及自定义主题
- **✏️ 实时编辑**：可直接在面板中编辑所有追踪器字段，并自动保存
- **💾 按重试（Swipe）存储数据**：每一次重试都保留各自独立的追踪器数据
- **🎛️ 追踪器配置**：可自定义追踪器的方方面面——增删数值、字段、小组件等等

### 智能特性

- **🔄 重试检测**：自动处理重试操作，并保持正确的追踪器上下文
- **📝 上下文感知**：天气、数值与角色状态会自然地影响叙事
- **🎭 多角色支持**：追踪所有在场角色的想法、关系与数值
- **📍 聊天中的想法气泡**：可选功能，在角色头像旁显示浮动想法气泡
- **🌈 自定义配色**：可使用自定义配色方案创建自己的主题
- **📱 移动端支持**：响应式设计，数值区域支持横向滚动
- **🔧 高级配置**：通过「追踪器设置」添加自定义数值、字段与小组件
- **🎨 颜色渐变**：数值条会根据数值大小在低值色与高值色之间平滑过渡
- **💬 多行格式**：为 AI 生成与解析提供清晰、结构化的格式
- **🧹 自动清理**：自动移除 AI 回复中的占位方括号

## ⚙️ 设置说明

### 主面板控制项

- **面板位置**：位于聊天的左侧或右侧
- **主题**：从 6 种内置主题中选择，或创建自定义主题
- **消息后自动更新**：每条消息后自动刷新 RPG 数据
- **上下文消息数**：生成更新时包含多少条最近的消息（仅「单独生成」模式）

### 显示选项

- **显示用户数值**：显示角色数值面板
- **显示信息框**：显示场景信息面板
- **显示角色想法**：显示 AI 角色的内心想法

### 生成模式

#### 集成模式（Together）

追踪器数据在主 AI 回复中一并生成，并被自动提取：

示例：
用户：走进酒馆

AI：追踪器数据 + 完整的角色扮演回复

↓ 扩展从回复中提取追踪器数据

↓ 显示在侧边栏面板中

↓ 主聊天区显示干净的角色扮演文本

优点：

- 只需一次 API 调用
- 响应更快
- 配置更简单

缺点：

- 追踪器格式混杂在 AI 回复中
- 可能轻微影响角色扮演质量

#### 单独模式（Separate）

追踪器数据在主回复之后通过单独的 API 调用生成：

示例：
用户：走进酒馆

AI：纯粹的角色扮演回复——不含追踪器数据

AI：单独一次调用，仅返回追踪器数据

↓ 扩展携带上下文发送单独请求

↓ AI 仅生成追踪器数据

↓ 显示在侧边栏面板中

↓ 上下文摘要注入到下一次生成中

优点：

- 角色扮演回复干净
- 角色扮演质量更好
- 上下文摘要增强沉浸感

缺点：

- 多一次 API 调用
- 速度略慢

### 模型选择

- **使用主聊天模型**：使用与聊天相同的模型（推荐）
- 自定义模型选择（即将推出）

## 📝 使用指南

### 快速开始

1. 在「扩展」标签页中启用本扩展
2. 选择生成模式：集成（Together）或单独（Separate）
3. 选择要显示哪些面板（用户数值、信息框、角色想法）
4. 开始聊天！追踪器会自动更新

### 编辑追踪器数据

你可以点击大多数字段进行编辑：

- **用户数值**：点击数值百分比、心情 emoji、状态字段、技能、物品栏物品或任务
- **信息框**：点击日期字段、天气、温度、时间、地点或近期事件
- **在场角色**：点击角色 emoji、名称、自定义字段、关系徽章或数值
- **想法气泡**：点击想法文本即可编辑（气泡会刷新以保持定位）

### 追踪器配置

通过「追踪器设置」按钮进行全面自定义：

**用户数值配置：**

- 以唯一名称添加/移除自定义数值
- 配置状态分区（心情 emoji + 自定义字段）
- 使用自定义技能字段配置技能分区
- 开关 RPG 属性显示

**信息框配置：**

- 启用/禁用各个小组件（日期、天气、温度、时间、地点、近期事件）
- 选择温度单位（摄氏度/华氏度）

**在场角色配置：**

- 添加自定义角色字段（外貌、动作、举止等）
- 配置关系状态选项
- 启用角色专属数值追踪
- 自定义想法气泡的标签与描述
- 所有字段都会在提示词中动态生成

### 重试（Swipe）支持

扩展完整支持重试功能：

- 每次重试都存储各自独立的追踪器数据
- 切换重试会加载该次重试对应的数据
- 生成新的重试时使用重试前已提交的数据
- 用户的手动编辑会在各次重试之间保留

### 手动更新

在单独生成模式下，你可以随时点击设置中的「刷新 RPG 信息」按钮来刷新 RPG 数据。

### 与引导生成（Guided Generations）的兼容性

本扩展会检测何时提交了「引导生成」提示词（例如通过 GuidedGenerations 扩展注入的临时 `instruct` 提示），并避免将其追踪器注入指令（请求数值、信息框与上下文提示词）加入生成上下文。这可以防止指令冲突，确保引导生成按用户预期运行。

如果你希望在引导生成时仍然应用追踪器提示，请通过单独生成模式执行更新，或暂时在另一个扩展中关闭引导生成。

RPG Companion 设置（高级分区）中新增了「在引导生成期间跳过追踪器与 HTML 注入」选项，现支持三种模式：

- none：从不跳过（照常注入追踪器提示词，默认值）
- impersonation：仅在检测到模拟（impersonation）式引导生成时跳过
- guided：只要检测到引导式 `instruct` 或 `quiet_prompt` 生成就跳过

## 🐛 故障排查

### 扩展未显示

- 刷新浏览器
- 重启 SillyTavern
- 确认已在「扩展」标签页中启用

### 数值未更新

- 检查「自动更新」是否已启用
- 尝试点击「手动更新」进行测试
- 确认你的 AI 后端响应正常
- 查看控制台中的错误信息

### 显示异常

- 尝试刷新页面
- 检查是否有其他扩展冲突
- 确认 CSS 已正确加载

### 想法气泡定位

- 气泡使用固定的 350px 宽度以保持定位一致
- 编辑后气泡会刷新以保持对齐
- 若问题依旧，尝试切换「角色想法」显示的开关

## 💡 使用技巧

1. **上下文消息数**：建议从 4 条开始，再根据实际需要调整。消息越多 = 上下文越充分，但更新越慢
2. **性能**：如果更新很慢，可考虑减少上下文深度或使用更快的模型
3. **自定义**：你可以修改 index.js 中的提示词，以添加自己的数值类别或更改格式
